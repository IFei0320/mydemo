
随着旅游业的快速发展与个性化出行需求的日益增长，传统旅游攻略在时效性、个性化和信息整合方面已难以满足游客需求。本文设计并实现了一套基于Django框架的智能旅游攻略生成系统。该系统融合多目标优化算法与大语言模型技术，为用户提供从目的地探索、数据可视化分析到个性化行程规划的一站式旅游决策支持。
系统采用B/S架构，基于Django 4.2和MySQL开发，整体划分为用户管理、旅游数据可视化、智能攻略生成和Wiki知识库四大模块。用户管理模块提供注册、登录、个人信息维护及头像上传等功能。数据可视化模块基于ECharts，从评分分布、热度排行、价格分析和区域分布四个维度展示旅游数据，帮助用户直观了解目的地概况。
智能攻略生成模块是系统的核心创新。该模块根据用户输入的目的地、季节、天数及预算等约束，先调用DeepSeek大语言模型生成城市旅游概览，再采用NSGA-II非支配排序遗传算法，以行程成本最小化、交通距离最小化、景点评分最大化和景点热度最大化为优化目标，对候选景点进行多目标优化求解，输出帕累托最优的行程方案集合。系统进一步利用大语言模型对选定方案进行文本润色，生成包含每日行程安排、交通建议和预算明细的结构化HTML报告，并支持将方案一键导出至滴答清单，实现规划与执行的无缝衔接。
Wiki知识库模块对原始旅游攻略文档进行LLM驱动的结构化编译，自动抽取摘要、实体、概念和知识卡片，建立关键词索引与交叉引用网络。在行程规划过程中，系统通过知识卡片匹配机制，将景点相关的实用信息（如最佳游览时间、购票建议、避坑指南等）注入优化与生成环节，显著提升了攻略内容的实用性和可靠性。
系统经功能测试与性能测试验证，各项指标均达到设计预期，能够有效支撑个性化旅游攻略的智能生成，为旅游推荐领域的智能化探索提供了可行方案。
关键词： 旅游攻略生成；Django框架；NSGA-II算法；大语言模型；检索增强生成




ABSTRACT

With the rapid development of the tourism industry and the growing demand for personalized travel, traditional travel guides can no longer meet tourists' needs in terms of timeliness, personalization, and information integration. This paper designs and implements an intelligent travel guide generation system based on the Django framework. Integrating multi-objective optimization algorithms and large language model (LLM) technology, the system provides one-stop travel decision support, covering destination exploration, data visualization analysis, and personalized itinerary planning.
The system adopts a B/S architecture and is developed with Django 4.2 and MySQL. It consists of four functional modules: user management, tourism data visualization, intelligent guide generation, and a Wiki knowledge base. The user management module provides basic functions such as registration, login, profile maintenance, and avatar upload. Based on ECharts, the data visualization module displays tourism data from four dimensions—rating distribution, popularity ranking, price analysis, and regional distribution—helping users gain an intuitive overview of destinations.
The intelligent guide generation module is the core innovation of the system. Based on constraints such as destination, season, number of days, and budget provided by the user, it first calls the DeepSeek LLM to generate a city travel overview. Then, it employs the NSGA-II non-dominated sorting genetic algorithm for multi-objective optimization, with the objectives of minimizing trip cost, minimizing transportation distance, maximizing attraction ratings, and maximizing attraction popularity. This yields a set of Pareto-optimal itinerary solutions. Subsequently, the system uses an LLM to refine the text of the selected solution and generates a structured HTML report containing daily schedules, transportation suggestions, and budget details. It also supports one-click export of the itinerary to TickTick, seamlessly connecting planning and execution.
The Wiki knowledge base module performs LLM-driven structured compilation on raw travel guide documents, automatically extracting summaries, entities, concepts, and knowledge cards, and building keyword indexes and a cross-reference network. During itinerary planning, a knowledge card matching mechanism injects practical attraction-related information (such as optimal visiting times, ticket purchase tips, and pitfalls to avoid) into the optimization and generation process, significantly improving the practicality and reliability of the generated guides.
Functional and performance tests verify that all system indicators meet the design expectations. The system can effectively support the intelligent generation of personalized travel guides, offering a feasible solution for intelligent exploration in the travel recommendation domain.
Keywords: travel guide generation; Django framework; NSGA-II algorithm; large language model; retrieval-augmented generation



第1章绪论
1.1项目背景及研究意义
1.1.1项目背景

近年来，居民生活水平持续提升，旅游已成为日常消费和节假日出行的重要内容。文化和旅游主管部门与国家统计部门公布的数据显示，国内旅游市场总体保持恢复增长，出游人次和旅游消费规模持续扩大[1][2]。旅游需求增长的同时，人们对行程安排的要求也在不断提高。过去，大家更关心“去哪里玩”，如今更在意“在有限的时间和预算内，怎样安排路线才更合理”。可见，旅游路线规划早已不只是信息查找的问题，而是一个需要综合权衡时间、空间、费用和个人偏好的现实决策问题。
实际出游时，用户通常需要同时考虑景点位置、交通方式、门票价格、开放时段、热门程度、季节因素以及预约规则等诸多内容。尤其在热门城市或短期出游场景下，用户往往要从大量攻略、游记和平台推荐中自行筛选信息这一过程不仅费时费力，还容易出现路线重复、预算超支或景点安排不合理等问题。虽然携程、马蜂窝、穷游等平台已经提供了丰富的旅游信息和服务，但这些平台更多解决的是“信息能查到”和“产品能买到”的问题，对“路线怎样安排更合适”的支持仍然比较有限[3]。
从现实需求看，旅游路线规划具有明显的多目标特点。用户通常希望在预算可控的前提下，尽量减少路程消耗、提升景点质量，并使整体体验更符合个人偏好。但这些目标之间并不完全一致：花费较低的路线未必体验最好，热门景点密集的路线又可能带来排队和拥挤问题。针对这一情况，多目标优化方法为旅游路线规划提供了一条较为可行的技术路径，尤其是遗传算法、NSGA-II 等方法，能够在多个目标之间寻求相对平衡的解[4][5]。
与此同时，智能问答与文本生成技术近几年发展较快，并已开始进入旅游应用场景。这类技术可以根据用户输入快速生成行程建议和文字说明，在交互体验上具有一定优势[6]。然而，完全依赖这类方法直接生成路线，容易出现内容不准确、信息过时或对预算、时长等条件考虑不充分的问题[7]。可见，单一方法往往难以满足真实旅游规划的需要。
旅游路线规划更适合采取“优化求解 + 知识补充 + 文字说明”相结合的方式来实现。从理论意义上看，本研究有助于推动旅游推荐从“推荐景点”向“规划路线”延伸，并将预算、距离、评分、热度和时段等要素纳入统一的分析框架。从实践意义上看，该研究可在一定程度上缓解用户制作攻略时面临的信息过载和行程安排困难，为在线旅游服务和个性化出行辅助系统提供参考。


1.1.2 研究意义
前文分析表明，旅游路线规划更适合走“优化求解 + 知识补充 + 文字说明”的路子：先用多目标优化产生合理的路线骨架，再用本地知识库补上时段、预约、交通、避坑等信息，最后输出容易读懂的行程说明。这样做既能提升方案本身的合理性，也让结果对普通用户更加友好。
从理论层面看，本研究将旅游推荐的重心从“推荐哪些景点”推向“怎样串成一条可行的路线”，尝试把预算、距离、评分、热度、时段等要素纳入统一框架来考虑，有助于丰富旅游推荐问题的建模方式。在实践层面，研究直接回应了用户做攻略时的信息过载与行程拼凑难题，能够为在线旅游平台和个性化出行助手提供一种可落地的思路。特别是将多目标优化与知识增强相结合，有望在保证方案质量的同时，弥补现有方法在信息丰富度和可读性上的短板，从而更好地衔接规划结果与用户的实际使用。
1.2 国内外研究现状
1.2.1 旅游推荐系统研究现状
旅游推荐系统的核心任务是根据用户兴趣、行为及景点特征，推荐更合适的旅游对象。早期工作以协同过滤、基于内容的推荐和规则方法为主，在景点、目的地及产品推荐中取得了一定成效[8][9]。随后，研究者逐步引入上下文信息和混合推荐机制，将用户行为、位置、出游时间等纳入考虑，提升了推荐的准确性和个性化程度[10]。
不过，现有研究大多解决的是“推荐什么”，对“怎么安排成一条完整的路线”关注较少。推荐系统可以给出若干值得去的景点，却很难处理景点间的时间衔接、空间顺序和预算约束。而对真实出行来说，用户需要的不是一份零散的清单，而是一条能直接照着走的行程。因此，将旅游推荐与路线规划相结合，已成为该领域的一个重要方向。
1.2.2 多目标优化在旅游路线规划中的应用研究
旅游路线规划与旅行商问题、车辆路径问题等经典组合优化问题高度相似，本质上是在多种约束下完成景点的选择与排序。针对这一问题，遗传算法、蚁群算法、粒子群算法、模拟退火及多目标进化算法等已被先后引入[11][12]。其中，NSGA-II 因能够同时处理多个相互冲突的目标而在旅游路线规划中受到较多关注[5]。
已有研究表明，多目标优化方法在兼顾成本、距离、时间与满意度等方面，比简单排序或人工规则更贴近实际需求[13]。但仍存在一些明显不足：一是部分研究停留在仿真层面，与真实数据和实际场景的结合较弱；二是不少研究偏重算法性能，忽视了输出结果的可理解性和易用性；三是对预约要求、最佳时段、拥挤程度等非结构化知识的利用普遍不足。因此，在多目标优化的基础上引入知识补充机制，是一个值得继续深挖的问题。
1.2.3 相关智能生成方法与知识增强研究趋势
近年来，智能问答与文本生成技术在旅游服务中的使用逐渐增多。这类方法可以直接理解用户的自然语言输入，并生成较完整的行程建议，交互体验有明显优势[6]。但实践也表明，它们在事实准确性、知识时效性和约束满足方面仍存在短板[7]。缺少外部知识支撑时，容易给出与真实开放时间不符的建议，或忽略预约、预算等关键条件。
为弥补这些不足，研究者开始引入知识图谱、检索增强生成（RAG）和本地知识库等方法，通过外部知识提升结果的可信度和可控性[14][15]。在旅游场景中，最佳游览时段、购票方式、交通贴士与人流提示等知识属性很强，很适合作为路线结果的补充信息。总体来看，旅游推荐、路径优化和文本生成各自取得了一定进展，但三者之间的结合还很不够。如何将多目标优化、知识补充与行程说明统一起来，形成面向真实场景的旅游路线规划系统，仍然具有重要的研究价值。
1.3 研究内容
针对现有旅游推荐难以直接形成完整路线、传统路径优化缺少知识补充、智能生成方法结果不够稳定等问题，本文围绕智能旅游路线规划系统的设计与实现展开研究。目标是：在用户给出城市、季节、预算、天数和偏好的基础上，自动生成兼顾成本、距离、评分与热度的旅游路线，并利用本地知识库和 Wiki 化资源对路线结果进行补充说明。
具体工作包括：第一，构建旅游景点结构化数据，整理本地旅游知识卡片与原始攻略资料，为路线规划打好数据基础；第二，采用 NSGA-II 多目标进化算法生成多组有代表性的候选路线方案；第三，设计知识命中与重排机制，将景点相关的最佳时段、预约提示、交通建议和避坑经验补充进路线结果；第四，对结构化结果进行文字化处理，使输出便于用户理解；第五，完成系统实现与功能验证，评估该方案在旅游路线规划任务中的实际效果。

第2章关键技术介绍2.1 Django Web框架
Django是Python生态中一款成熟的Web开发框架，以开发效率高、结构清晰、易于维护著称。本系统选用Django 4.2作为后端框架，主要考虑其文档完善、功能齐全，能够较好地支撑旅游路线规划系统中的数据管理、业务逻辑处理和页面交互。
Django采用MTV模式，即Model（模型）、Template（模板）和View（视图）。Model负责数据结构与数据库的映射，Template负责页面渲染，View负责请求处理与业务逻辑。本系统中的景点信息、用户输入、路线结果等都可以按这一模式组织，使整体结构更为清晰。Django内置的ORM机制允许开发者通过Python类来完成数据库表的定义与操作，省去了大量手写SQL的工作。此外，其路由系统便于各功能模块独立组织，中间件机制也有助于统一实现日志记录、权限控制等通用功能。综合来看，Django能够较好地满足本系统快速开发与后续维护的需求。
2.2 多目标优化与NSGA-II算法
旅游路线规划本质上是一个多目标优化问题。用户在安排行程时，通常希望在预算可控的前提下，尽量减少路程、提高景点评分、优化整体体验。但这些目标之间往往相互牵制，无法用单一指标来衡量。多目标优化问题的一般形式可表示为：
min F(x) = (f₁(x), f₂(x), …, fₘ(x)) 
其中，x为决策变量，在本文中指景点的选择与访问顺序；F(x)为目标函数向量。与单目标优化不同，多目标优化通常不存在唯一最优解，而是得到一组彼此无法简单比较优劣的解，这组解被称为Pareto最优解。若解x₁在所有目标上都不劣于x₂，且至少在一个目标上优于x₂，则称x₁支配x₂。
本系统的优化目标共有四个：总门票成本尽量低、景点间总路程尽量短、平均评分尽量高、平均热度尽量高。为统一求解方向，评分和热度在计算时转化为最小化负值。同时，路线还需满足预算约束、出游天数约束及同城约束。通过以上处理，旅游路线规划问题被转化为一个标准的多目标优化问题。
在求解方法上，本文采用NSGA-II算法。NSGA-II是一种经典的多目标进化算法，具有排序速度快、解集分布均匀、精英保留效果好等优点，在路径规划和组合优化问题中应用广泛。其基本思路是：通过种群的不断迭代，在多个目标之间逐步搜索出更合理的平衡解。
在本系统中，NSGA-II的应用流程大致为：先根据城市信息筛选候选景点，生成初始路线种群；然后计算每条路线在花费、距离、评分和热度上的表现；再通过非支配排序、选择、交叉和变异反复迭代；最终得到一组Pareto候选解，并进一步整理为省钱型、均衡型和体验型等不同风格的方案。相比简单的排序方法，该算法能够更有效地兼顾多个目标，因而更适用于旅游路线规划问题。
2.3 检索增强生成（RAG）
在旅游路线规划系统中，完全依赖模型直接生成结果容易出现内容不准确或依据不足的问题。检索增强生成（RAG）的核心思路是“先检索，再生成”——先从外部知识中找出相关信息，再将这部分内容作为补充融入结果整理过程。
本系统的知识增强采用了轻量化的实现方式，未引入向量数据库，而是基于本地Markdown Wiki、JSON知识卡片和关键词匹配规则来完成检索。系统根据城市和路线涉及的景点进行匹配，提取出最佳游览时段、预约建议、交通提示和避坑信息。这种方式虽然在语义检索的灵活性上不如标准RAG，但实现更简便，也更能适配当前系统的实际需求。
2.4 MySQL数据库
MySQL是一种广泛应用的开源关系型数据库管理系统。本系统选择MySQL作为数据存储方案，主要基于以下几点考虑：它性能稳定可靠，支持灵活的事务处理，提供丰富的数据类型和功能，同时具备良好的安全性与高可用性。无论是小型Web应用还是大型企业级系统，MySQL都能提供高效、稳定的数据存储与管理服务。在本系统中，MySQL负责存储用户信息、景点数据、路线结果等核心数据，与Django的ORM机制配合使用，开发效率较高。
