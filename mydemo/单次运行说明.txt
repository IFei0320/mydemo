================================================================
  论文图表单次生成脚本 —— 运行说明
  每个脚本仅运行一轮，生成一张图 + 一份JSON数据
================================================================

【启动虚拟环境】
执行以下命令激活虚拟环境（每次打开新终端只需执行一次）：

PS D:\ass\mydemo> (Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned) ; (& d:\ass\mydemo\venv\Scripts\Activate.ps1)

激活成功后终端前缀变为 (venv) PS D:\ass\mydemo>

================================================================
【运行单个脚本】

(venv) PS D:\ass\mydemo> python home\tests_algorithms\quick_runs\quick_pareto.py

(venv) PS D:\ass\mydemo> python home\tests_algorithms\quick_runs\quick_convergence.py

(venv) PS D:\ass\mydemo> python home\tests_algorithms\quick_runs\quick_algo_compare.py

(venv) PS D:\ass\mydemo> python home\tests_algorithms\quick_runs\quick_sensitivity_pop.py

(venv) PS D:\ass\mydemo> python home\tests_algorithms\quick_runs\quick_sensitivity_gen.py

(venv) PS D:\ass\mydemo> python home\tests_algorithms\quick_runs\quick_sensitivity_budget.py

(venv) PS D:\ass\mydemo> python home\tests_algorithms\quick_runs\quick_sensitivity_cost.py

================================================================
【输出文件说明】

图表（SVG格式）保存在  diagrams\output\ 目录：
  Pareto前沿图.svg            —— 成本-评分 + 成本-路程 双子图
  收敛曲线图.svg              —— 超体积收敛 + 质量可行性 双子图
  算法对比图.svg              —— NSGA-II/贪心/随机 五维柱状对比
  种群敏感性图.svg            —— 种群大小对HV和运行时间的影响
  代数敏感性图.svg            —— 进化代数对收敛性和可行性的影响
  预算敏感性图.svg            —— 预算约束对可行性和Pareto多样性的影响
  预算成本匹配图.svg          —— 预算与实际成本的匹配关系

数据（JSON格式）保存在  diagrams\data\ 目录：
  Pareto前沿数据.json
  收敛曲线数据.json
  算法对比数据.json
  种群敏感性数据.json
  代数敏感性数据.json
  预算敏感性数据.json
  预算成本匹配数据.json

================================================================

  脚本                        估算时间
  quick_pareto.py             约 10-20 秒
  quick_convergence.py        约 1-2 分钟
  quick_algo_compare.py       约 1-2 分钟

  quick_sensitivity_budget.py 约 2-3 分钟
  quick_sensitivity_cost.py   约 2-3 分钟

注：具体时间取决于数据库景点数量和机器性能。
