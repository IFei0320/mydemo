# 旅游数据分析平台 — 项目概述与技术架构

## 1. 项目简介

本项目是一个基于 Django 的**旅游数据分析与智能路线规划平台**。核心功能包括：

- 全国旅游景点数据的爬取、清洗、存储与可视化分析
- 基于 DeepSeek 大模型的 AI 旅游攻略生成
- 基于 NSGA-II 多目标遗传算法的智能旅游路线规划
- 基于 LLM 的 Wiki 知识库系统（文档摄入 → 结构化存储 → 语义查询 → 健康检查）
- 路线结果一键导出到滴答清单

**使用场景**：用户输入城市、季节、预算、天数，系统通过多目标优化算法生成 3 个帕累托最优路线方案，并调用大模型为选定方案生成详细的 HTML 报告。

## 4. 整体数据流

```
携程API ──爬虫──→ CSV ──清洗──→ MySQL ◄── 两种方式 ──┐
                                         │              │
                                    pymysql直连    Django ORM
                                    (KSH分析页)   (首页/列表/NSGA2)
                                         │              │
                                    part表数据     TravelInfo模型
                                         │              │
                                         ▼              ▼
                                    ECharts图表    NSGA-II算法
                                                   │
原始攻略文档(raw/) ──LLM编译──→ Wiki知识库 ────→ RAG知识增强
                                                   │
                                                   ▼
用户输入(城市/季节/预算/天数) ──→ DeepSeek API ──→ AI攻略/HTML报告
                                                   │
                                                   ▼
                                              滴答清单导出
```

### 关键数据流说明

1. **数据采集流**：`spider.py` 爬取携程 API → 存入 CSV → `data_pro.py` 清洗去重 → `csv_to_sql.py` 导入 MySQL
2. **首页展示流**：Django ORM 查询 TravelInfo 表 → 统计聚合 → 模板渲染 → ECharts 图表
3. **KSH 分析流**：pymysql 直连查询离线计算表（part1~part8）→ ECharts 可视化
4. **AI 速览流**：用户输入 → views.get_ai_travelRoute → Get_DeepSeek → DeepSeek API → JSON → 前端地图标注
5. **NSGA-II 规划流**：用户输入 → build_candidates(ORM查景点) → run_nsga2(多目标进化) → Top3方案 → 用户选择 → call_ai_refiner(AI润色) + call_ai_html_report(HTML报告)
6. **Wiki 知识流**：raw/ 文档 → wiki_llm.compile_raw(LLM编译) → wiki_store 写入文件 → query_wiki 关键词检索 + LLM回答 → retrieve_wiki_knowledge_cards 路线增强
7. **导出流**：用户确认方案 → views_dida.export_to_dida_checklist → 滴答 API 创建任务
