# 数据层 — 模型、爬虫、数据处理

## 1. 数据采集（spider.py）

### 1.1 概述

`data/spider.py` 是携程旅行网的数据爬虫，调用携程移动端 API 获取指定城市的景点列表。

### 1.2 核心流程

```
cityDict(城市→districtId) → for page in 1..30 → POST API → 解析JSON → 写入CSV
```

### 1.3 关键组件

**请求配置**（第5-46行）：模拟携程 App 的 HTTP 请求头（User-Agent、Referer、Cookie 等），绕过反爬。

**API 接口**（第49行）：
```
POST https://m.ctrip.com/restapi/soa2/18109/json/getAttractionList
```

**get_json(k, v, page)** — 构造请求体，向携程 API 发送 POST 请求，返回 JSON 响应。
- `k`：城市中文名（如"上海"）
- `v`：携程 districtId
- `page`：分页索引

**get_data_info(resp, k)** — 解析 API 响应中的 `attractionList`，提取每个景点的 22 个字段（poiId、名称、评分、价格、经纬度、热度等），写入 CSV。

**write_header()** — 写入 CSV 表头（23 列）。

**主程序**（第137-153行）：
```python
cityDict = {"上海": 2}  # 可扩展更多城市
for k, v in cityDict.items():
    for page in range(1, 30):  # 每城市最多290条
        resp = get_json(k, v, page)
        get_data_info(resp, k)
```

## 2. 数据清洗（data_pro.py）

### 2.1 概述

读取爬虫生成的 `data.csv`，执行清洗操作后输出 `data_pro.csv`。

### 2.2 处理步骤

1. **读取 CSV**：用 pandas 读取，指定中文列名
2. **去重**：按 `唯一标识`（poiId）去重
3. **填充缺失值**：评分、热度评分、评论数量填 0
4. **清理标签格式**：移除标签列中的 `[`、`]`、`"` 字符
5. **输出**：写入 `data_pro.csv`

## 5. 数据库工具（utils/util.py）

### 5.1 概述

封装 pymysql 连接操作，因为 Python 3.14 当时无法正常使用 mysqlclient（C 扩展），改用纯 Python 实现的 pymysql。

### 5.2 函数说明

**get_db()** — 建立数据库连接，返回 `(conn, cursor)` 元组。
- 从 `.env` 读取 DB_HOST、DB_USER、DB_PASSWORD、DB_NAME
- 使用 utf8mb4 编码

**query(sql, params=None)** — 执行 SELECT 查询。
- 支持参数化查询（防 SQL 注入）
- 返回 `cursor.fetchall()` 的结果集

**execute(sql)** — 执行 INSERT / UPDATE / DELETE。
- 自动 commit

### 5.3 与 Django ORM 的关系

项目中同时存在两种数据库访问方式：

| 方式 | 使用位置 | 用途 |
|------|----------|------|
| Django ORM | home/views.py, home/views_nsga2.py, ksh/views.py (part3/part4) | 景点数据查询、首页统计 |
| pymysql 直连 | ksh/views.py (part1/part2) | 离线分析表查询 |

两套方式并存的原因是 KSH 分析页依赖预计算的离线表（part1~part8），这些表不是 Django Model。

    market_price = models.CharField(max_length=255, null=True)

    discount_description = models.CharField(max_length=255, null=True)

## 7. 数据处理工具函数（home/data_utils.py）

这是整个项目的**数据解析基础设施**，被 NSGA-II 算法和 KSH 分析视图共同使用。

### 7.1 常量

- `SEASON_KEYWORDS`：四季对应的景点标签关键词（如春季→"花"、"樱"、"踏青"）
- `CHINA_LON_MIN/MAX`、`CHINA_LAT_MIN/MAX`：中国地理坐标范围

### 7.2 函数

**_safe_float(raw_value, default=0.0)** — 安全地将任意值转为浮点数。
- 处理 None、空字符串、非数字字符串
- 如果直接转换失败，用正则提取数字部分再尝试

**_parse_price(raw_value)** — 解析价格字符串。
- "免费" → 0.0
- 其余调用 _safe_float

**_parse_distance_km(raw_value)** — 解析距离字符串，统一转为公里。
- 含"m"但不含"km"的视为米，除以1000

**_haversine_km(lon1, lat1, lon2, lat2)** — 使用 Haversine 公式计算两点球面距离。

**_is_valid_china_coord(lon, lat)** — 验证坐标是否在中国境内。

**_normalize_coord_pair(lon_raw, lat_raw)** — 标准化坐标对。
- 将字符串转为浮点数
- 验证是否在中国境内
- 如果经纬度疑似交换（lat在lon范围、lon在lat范围），自动纠正

**_season_bonus(tags, season)** — 计算季节匹配加成。
- 根据景点标签与当季关键词的命中数，返回 0~0.4 的评分加成
