### home/nsga2_trip_planner.py — NSGA-II 算法核心

**数据结构**：

| 类/函数 | 功能 |
|---------|------|
| `ScenicSpot` (dataclass) | 景点数据结构：name, city, area, tags, rating, hotness, reviews, cost, lon, lat, center_distance_km |

**函数详解**：

| 函数 | 功能 |
|------|------|
| `build_candidates(queryset, city, season)` | 从 TravelInfo 表构建候选景点集：城市过滤 → 精确匹配优先 → 解析评分/热度/票价/坐标 → 应用季节加成 |
| `_evaluate_route(route_indices, spots, per_day)` | 评价单条路线：计算 cost/distance/rating/hotness/reviews 5 个指标 |
| `_fast_non_dominated_sort(population)` | 快速非支配排序：给每个个体分配 rank（帕累托层级） |
| `_crowding_distance(population, front)` | 拥挤距离：边界点无穷大，内部点计算相邻目标差值之和 |
| `_tournament(population)` | 锦标赛选择：随机选两个，先比 rank 再比 crowding distance |
| `_ordered_crossover(parent_a, parent_b)` | 有序交叉（OX）：随机切点 + 从另一父代按序填充 |
| `_mutate(route, candidate_count, mutation_rate)` | 变异：交换变异（20%）+ 替换变异（20%）+ _repair_unique 修复 |
| `_repair_unique(route, candidate_count)` | 修复重复基因：用未使用的候选 ID 替换重复项 |
| `_evaluate_population(population, spots, per_day, budget)` | 种群评估：计算每个个体的 4 个目标值，超预算个体赋 1e9 惩罚 |
| `run_nsga2(spots, days, budget, per_day, pop_size, generations)` | 主算法：初始化 → 迭代（选择→交叉→变异→合并→精英选择）→ 返回帕累托前沿 |
| `choose_solution(pareto_set, sensitivities, budget)` | 加权效用函数选择均衡解（价格/距离/热度/评分/拥挤 5 维权重） |
| `build_route_payload(best_solution, spots, days, per_day)` | 将整数索引数组转为结构化路线 JSON（含 visit_time/features/坐标/费用） |

### static/ksh/js/part1.js — 评分分析页

ECharts 双图表：
- Chart1：环形玫瑰饼图（评分分布占比）
- Chart8（part8 div）：柱状+折线混合图（双 Y 轴，省份数量 vs 平均评分），含 dataZoom + toolbox

### static/ksh/js/part2.js — 热度分析页

ECharts 双图表 + 动态筛选：
- Chart1：漏斗图（评论数排行）
- Chart2：横向柱状图（城市热度评分）
- `loadChartData()` — AJAX GET /ksh/get_cityData 异步加载
- `updateChart(data)` — ECharts setOption 更新
- 下拉框 change 事件触发 `loadChartData()`

数据来自 `window.part2Config`（初始）和 AJAX（筛选后）。
