# CSRF Token 处理分析：Bug 还是 Feature？

## 结论：**不是 Bug，是冗余的安全措施（Feature），但存在 jQuery 重复加载的问题。**

---

## 1. 实际脚本加载顺序（get_ai_travelRoute.html）

由于 `{% block content %}` 渲染在 base.html 的 `{% block extra_js %}` **之前**，最终 HTML 中脚本顺序为：

```
① get_ai_travelRoute.html:171  jQuery.min.js  ← 第一次加载
② get_ai_travelRoute.html:172  Baidu Maps API
③ get_ai_travelRoute.html:175  window.travelRouteConfig 定义
④ get_ai_travelRoute.html:182  get_ai_travelRoute.js（内部使用 $(document).ready）
⑤ base.html:179               jQuery.min.js  ← 第二次加载（覆盖 $）
⑥ base.html:180-185           bootstrap, waves 等
⑦ base.html:195               $.ajaxSetup({...})  ← 此时 jQuery 可用
```

## 2. $.ajaxSetup 是否生效？

**生效。** 因为：
- `$.ajaxSetup` 在 base.html:195 执行时，jQuery 已经在第⑤步加载完毕
- get_ai_travelRoute.js 中的 `$.ajax()` 调用使用当前的 `$`（即第二次加载的 jQuery 实例），它包含 `$.ajaxSetup` 的设置

**所以手动传 `X-CSRFToken` header 是冗余的**——`$.ajaxSetup` 的 `beforeSend` 会自动添加。

## 3. 关于开发者注释中的担忧

> "jQuery 在此页面才引入，base.html 的 $.ajaxSetup 在 base.html 底部执行时 jQuery 可能尚未加载"

**这个担忧不成立。** 实际上 jQuery 在 base.html:179 就加载了，`$.ajaxSetup` 在 base.html:195 执行时 jQuery 可用。

## 4. 存在的真实问题：jQuery 重复加载

| 位置 | 文件 |
|------|------|
| 第1次 | get_ai_travelRoute.html:171 |
| 第2次 | base.html:179 |

对比 `ai_nsga2_route.html`——它正确地使用 `{% block extra_js %}` 放置脚本，**不重复加载 jQuery**：

```html
<!-- ai_nsga2_route.html (正确做法) -->
{% endblock %}  <!-- content block 结束 -->

{% block extra_js %}
<script src="{% static 'assets/js/echarts/echarts.min.js' %}"></script>
<script>
window.nsga2RouteConfig = { ..., csrfToken: '{{ csrf_token }}' };
</script>
<script src="{% static 'ksh/js/ai_nsga2_route.js' %}"></script>
{% endblock %}
```

## 5. 建议的修复

将 `get_ai_travelRoute.html` 中的脚本从 `{% block content %}` 移到 `{% block extra_js %}`，与 `ai_nsga2_route.html` 保持一致。

### 修改文件
- `templates/ksh/get_ai_travelRoute.html`

### 修改内容
1. 在 `{% block content %}` 结束标签前，**删除**第 170-182 行的 `<script>` 标签
2. 添加 `{% endblock %}` 关闭 content block
3. 添加 `{% block extra_js %}` 块，包含：
   - echarts 引入
   - Baidu Maps API 引入
   - `window.travelRouteConfig` 定义
   - `get_ai_travelRoute.js` 引入
4. **删除**手动 `headers: { 'X-CSRFToken': ... }`，因为 `$.ajaxSetup` 会自动处理

### 修改后效果
- jQuery 只加载一次（由 base.html 加载）
- `$.ajaxSetup` 在 jQuery 加载后执行，自动处理 CSRF
- 不再需要手动传 CSRF token
- 与 `ai_nsga2_route.html` 模式一致

## 6. 验证方式

1. 打开浏览器开发者工具 Network 面板
2. 提交表单，检查 AJAX 请求是否携带 `X-CSRFToken` header（由 `$.ajaxSetup` 自动添加）
3. 检查页面中 jQuery 只加载一次
4. 确认请求成功（200 状态码）
